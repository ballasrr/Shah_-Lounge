# Бэкенд «Шах Lounge»

API на Python (FastAPI) для того, что статическому сайту не сделать самому. Сейчас — статусы столов из iiko:
свободен, занят, забронирован. Ключ iiko хранится только здесь, на сайт уходит готовый список без имён гостей и сумм.

На сервере nginx отдаёт сайт как раньше, а запросы `/api/...` передаёт сюда.

## Запуск у себя

Нужен Python 3.12 или новее.

```bash
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # на Linux: .venv/bin/python
.venv/Scripts/python -m uvicorn app.main:app --port 8000 --reload
```

- http://localhost:8000/api/tables — столы и статусы
- http://localhost:8000/api/docs — описание API

Пока в `backend/.env` нет ключа iiko, сервер отдаёт тестовый зал (`"demo": true`), статусы в нём меняются раз в 5 минут.

Тесты: `.venv/Scripts/python -m pytest`

## Подключение iiko

1. Получить ключ iikoCloud API (`apiLogin`) — см. ниже.
2. `cp .env.example .env` и вписать ключ в `IIKO_API_LOGIN`.
3. `python -m app.discover` — покажет организации, группы терминалов, залы, столы и сегодняшние брони.
   ID организации и группы терминалов можно вписать в `.env`; без них берутся первые доступные.
4. Перезапустить сервер: в ответе станет `"demo": false`.

### Где взять ключ

Ключ создаётся в **iikoWeb** (личный кабинет iiko в браузере) в настройках облачного API — раздел называется
«iikoCloud API» или «API-логины». При создании отметить организацию «Шах» и права на заказы и резервы.

При создании обязательно добавить точку на вкладке «Подключённые точки», иначе ключ не сохранится.

Новые ключи iiko принимает только вместе с данными приложения: зарегистрируйся на портале разработчиков
https://public-api.iikoweb.ru/portal, создай приложение и впиши его `appId` и `clientSecret`
в `IIKO_APP_ID` и `IIKO_CLIENT_SECRET`. `clientSecret` показывают один раз — сохрани сразу.

Если раздела Cloud Api в iikoWeb нет — услуга iikoCloud API не подключена: её включает ваш дилер iiko (тот, кто ставил и обслуживает iiko).
Брони будут видны, только если подключён модуль резервов и персонал заводит брони в iiko.

Ключ — как пароль: не отправлять в мессенджеры и не коммитить, только в `backend/.env` на сервере.

## Ответ `/api/tables`

```json
{
  "updatedAt": "19:00",
  "demo": false,
  "stale": false,
  "tables": [
    { "id": "…", "number": 5, "name": "Стол 5", "seats": 4, "section": "Зал", "status": "reserved", "reserved_at": "20:30" }
  ]
}
```

- `status`: `free` — свободен, `busy` — на столе открыт заказ, `reserved` — бронь идёт сейчас или начнётся в ближайшие 2 часа
- `stale: true` — iiko не ответил, показаны последние полученные данные
- в iiko сервер ходит не чаще раза в 30 секунд, сколько бы посетителей ни было на сайте
